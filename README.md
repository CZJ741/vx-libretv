# LibreTV 微信小程序版 (原生 + 微信云开发)

本项目是 LibreTV 的微信小程序原生实现 Demo 版本，采用原生开发框架与微信云开发能力。

---

## 一、 架构与设计

### 1. 为什么使用微信云开发？
- **免配置域名白名单与解决跨域**：微信小程序对 `wx.request` 请求的域名有严格的合法域名白名单与备案要求，且多数采集站属于 HTTP 或未在白名单中。通过**微信云函数**（Node.js）进行请求聚合与中转代理，无需在小程序后台逐个配置第三方采集源域名。
- **免服务器运维**：开箱即用，无需单独购置、部署和维护云服务器。

### 2. 目录结构
```text
LibreTV-miniapp/
├── cloudfunctions/             # 云函数目录
│   └── cmsProxy/               # 多源搜索与详情代理云函数
│       ├── index.js            # 云函数逻辑实现（聚合、分组、清洗、详情解析）
│       └── package.json        # 依赖配置（wx-server-sdk, axios）
├── miniprogram/                # 小程序前端原生代码
│   ├── pages/
│   │   ├── index/              # 首页：多源聚合搜索、卡片流
│   │   ├── detail/             # 详情页：剧集概览、源线路切换、选集
│   │   └── player/             # 播放器页面：原生 video 组件（支持 HLS/M3U8）、连播
│   ├── app.js                  # 云环境初始化
│   ├── app.json                # 路由及全局窗口配置
│   ├── app.wxss                # 暗黑系统一全局样式
│   └── sitemap.json
└── project.config.json         # 微信开发者工具配置文件
```

## 二、 运行与部署步骤

### 1. 导入微信开发者工具
1. 打开 **微信开发者工具**。
2. 选择 **导入项目**。
3. 目录选择平级生成的目录：`E:\LibreTV-miniapp`。
4. AppID 可以选择你自己的测试号或已开通云开发的小程序 AppID。

### 2. 开通与配置云开发
1. 在微信开发者工具顶部工具栏，点击 **云开发** 按钮开通环境（若未开通）。
2. 在 `miniprogram/app.js` 中，可配置当前的环境 ID：
   ```js
   wx.cloud.init({
     env: '你的云开发环境ID', // 替换为你创建的环境ID
     traceUser: true,
   });
   ```

### 3. 安装与上传云函数
1. 在微信开发者工具中，展开目录 `cloudfunctions/cmsProxy`。
2. 右键点击 `cmsProxy` 文件夹，选择 **“上传并运行：云端安装依赖”**（或者在本地执行 `npm install` 后选择“上传并运行：所有文件”）。

### 4. 预览与测试
- 在开发者工具中编译运行。
- 点击热门推荐标签或输入影片名（如“繁花”、“庆余年”）。
- 点击搜索结果进入详情，可切换非凡、如意、暴风、量子等不同资源源。
- 点击集数进入播放页面直接观看。
